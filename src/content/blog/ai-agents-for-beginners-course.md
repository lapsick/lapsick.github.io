I recommend [Microsoft's AI Agents for Beginners](https://github.com/microsoft/ai-agents-for-beginners)
— a free, 18-lesson course that walks through building AI agents from the fundamentals up to
production, security, and local deployment. The code samples are built on the **Microsoft Agent
Framework (MAF)** together with **Microsoft Foundry Agent Service**.

A few things worth knowing about the course:

- **Multi-language.** It's translated into 50+ languages via an automated GitHub Action, so
  translations stay in sync with the source as it's updated.
- **Kept current.** Recent lessons cover MAF, agentic protocols (MCP, A2A), context engineering,
  agent memory, and securing agents — not just the fundamentals.
- **Python and .NET.** MAF supports both, so the same patterns carry across languages.
- **Hands-on.** Each lesson pairs a written README and a short video with runnable code samples.
- **Flexible entry.** Lessons are self-contained, so you can start at whichever topic you need
  rather than working through the whole thing linearly.

If you're building agentic systems — or evaluating whether MCP and A2A belong in your
architecture — it's a solid, low-friction way to get hands-on with the current tooling before
committing to a design.
